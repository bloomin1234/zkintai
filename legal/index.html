Z勤怠 利用規約

本規約は、勤怠・給与計算サービス「Z勤怠」の利用条件を定めるものです。

第1条（適用）

本規約は、ブルーミン・デジタル・アンド・ストラテジー株式会社（以下「当社」といいます）が提供する勤怠・給与計算サービス「Z勤怠」（以下「本サービス」といいます）の利用に関し、当社と利用者との間の一切の関係に適用されます。利用者は、本規約に同意のうえ本サービスを利用するものとします。

第2条（定義）

  1. 「利用者」とは、本規約に同意し本サービスを利用する法人・団体・個人事業主をいいます。
  2. 「アカウント」とは、本サービスの利用のために利用者が登録する識別情報をいいます。
  3. 「業務データ」とは、利用者が本サービスに入力・保存する従業員情報、勤怠情報、給与情報その他の情報をいいます。

第3条（アカウント登録）

  1. 利用者は、会社名・メールアドレス・パスワードを登録することでアカウントを作成します。
  2. 利用者は、登録情報を正確かつ最新に保つものとします。
  3. パスワードその他の認証情報の管理は利用者の責任とし、第三者による利用・漏えいについて当社は責任を負いません。
  4. 一つのアカウントを複数の担当者で利用する場合、その管理は利用者の責任で行うものとします。

第4条（料金および支払い）

  1. 本サービスの利用料金は、本サービス上に表示する料金プランに従います。プランは在職従業員数により自動的に判定されます。
  2. 支払いは、Stripe, Inc. の決済システムを通じたクレジットカード払いとします。
  3. 登録時にカード情報を登録のうえ、7日間の無料お試し期間が適用され、8日目以降に自動的に課金が開始されます。
  4. 解約は契約画面からいつでも行えます。無料お試し期間内に解約した場合、料金は発生しません。
  5. 当社は、いったん支払われた料金の返金（日割り返金を含む）を行いません。
  6. 当社は、料金プランおよび料金を改定することがあります。改定する場合は、相当な期間をもって本サービス上に表示する方法等により告知します。

第5条（本サービスの内容・無保証）

  1. 本サービスは「現状有姿（as-is）」で提供されます。当社は、本サービスの完全性・正確性・有用性・特定目的への適合性・継続性・安全性等について、明示・黙示を問わず、いかなる保証も行いません。
  2. 本サービスが算出する給与計算の結果、配信・表示する保険料率・税額表その他の情報は参考値であり、当社はその正確性・最新性・法令適合性を保証しません。利用者は、計算結果その他を適用・確定する前に、必ず国税庁・全国健康保険協会（協会けんぽ）・日本年金機構等の公式情報および自社の就業規則・労使協定等と照合し、自らの責任で確認・判断するものとします。これらに起因して利用者または第三者に生じた一切の損害について、当社は責任を負いません。

第6条（データの保存・バックアップ）

  1. 業務データは、利用者の端末のブラウザ内およびクラウド上の利用者専用領域に保存されます。
  2. 業務データのバックアップは利用者の責任で行うものとします（本サービスはデータの書き出し機能を提供します）。
  3. 端末の故障・変更・紛失、ブラウザデータの消去、通信障害、クラウドサービスの障害その他の事由による業務データの消失・毀損について、当社は責任を負いません。

第7条（サービスの中断・変更・終了）

  1. 当社は、保守・点検、障害対応、その他当社が必要と判断した場合、事前の通知なく本サービスの全部または一部の提供を中断・停止することができます。
  2. 当社は、本サービスの内容を任意に変更・追加し、または本サービスの提供を終了することができます。提供を終了する場合は、可能な範囲で事前に告知するよう努めます。
  3. 本条に基づく中断・変更・終了により利用者に生じた損害について、当社は責任を負いません。

第8条（禁止事項）

利用者は、本サービスの利用にあたり、次の行為をしてはなりません。

  1. 法令または公序良俗に違反する行為
  2. 当社または第三者の権利・利益を侵害する行為
  3. 本サービスの複製・改変・解析（リバースエンジニアリング等）、不正アクセス、その運営を妨害する行為
  4. 当社の事前の許可なく本サービスを再販売・再配布・転用する行為
  5. 虚偽の情報を登録する行為
  6. その他、当社が不適切と合理的に判断する行為

第9条（利用者の責任）

  1. 利用者は、本サービスに入力するデータの正確性について責任を負います。
  2. 利用者は、自社の従業員等の個人情報の取得・利用・管理について、個人情報保護法、労働関連法令その他の適用法令を遵守し、必要な通知・同意取得等の手続を自らの責任で行うものとします。

第10条（損害賠償の制限）

  1. 当社は、本サービスに関連して利用者に生じた損害について、当社の故意または重過失による場合を除き、責任を負いません。
  2. 前項にかかわらず当社が責任を負う場合であっても、当社の賠償責任は、利用者に現実に発生した直接かつ通常の損害に限られ、逸失利益、特別損害、間接損害、データの消失・毀損による損害、第三者からの請求に基づく損害等については、当社は責任を負いません。
  3. 当社が利用者に対して負う損害賠償の総額は、損害発生の直前1か月間に当該利用者が当社に対して実際に支払った本サービスの利用料金の額を上限とします。
  4. 消費者契約法その他の強行法規により前各項の全部または一部が適用されない場合、当社の責任はその限度で認められる範囲に従うものとします。

第11条（個人情報の取扱い）

本サービスにおける個人情報の取扱いは、別途定める「プライバシーポリシー」によるものとします。

第12条（権利帰属）

本サービスおよびこれに関連する一切の知的財産権は、当社または正当な権利者に帰属します。本規約は、利用者に対し本サービスの利用権を許諾するものであり、知的財産権を移転するものではありません。

第13条（本規約の変更）

当社は、必要と判断した場合、本規約を変更することができます。変更後の本規約は、本サービス上に表示した時点から効力を生じるものとし、変更後に利用者が本サービスを利用した場合、変更に同意したものとみなします。

第14条（準拠法・合意管轄）

本規約は日本法に準拠して解釈されます。本サービスまたは本規約に関して当社と利用者との間に紛争が生じた場合、東京地方裁判所を第一審の専属的合意管轄裁判所とします。

プライバシーポリシー

ブルーミン・デジタル・アンド・ストラテジー株式会社（以下「当社」）は、勤怠・給与計算サービス「Z勤怠」（以下「本サービス」）における個人情報を、以下の方針に基づき適切に取り扱います。

1. 取得する情報

  • アカウント情報：会社名、メールアドレス、パスワード（暗号化して保管します）
  • 業務データ：利用者が入力する従業員の氏名・社員コード・部署・給与情報・勤怠情報等
  • 決済情報：クレジットカード情報は Stripe, Inc. が処理し、当社はカード番号等を保持しません
  • 利用情報：アクセスログ等、本サービスの提供に伴い取得する情報

2. 利用目的

  • 本サービスの提供・運営・本人確認のため
  • 料金の請求・決済のため
  • お問い合わせへの対応のため
  • 本サービスの改善および不正利用の防止のため
  • 重要なお知らせ等を連絡するため

3. 業務データの位置づけ

利用者が本サービスに入力する従業員情報等の業務データは、利用者がその管理について責任を負う情報です。当社はこれらを利用者専用のデータ領域に保管し、行レベルセキュリティ（RLS）により他の利用者からアクセスできないようにしています。当社は、本サービスの提供・保守に必要な範囲を超えてこれらのデータを利用しません。利用者は、自社の従業員等の個人情報の取得・利用について、個人情報保護法その他の法令上必要な手続（通知・同意取得等）を、自らの責任で行うものとします。

4. 第三者提供・委託先

当社は、次の場合を除き、あらかじめ利用者の同意を得ることなく個人情報を第三者に提供しません。

  • 法令に基づく場合
  • 本サービスの運営に必要な業務委託先（クラウドインフラ：Supabase（Supabase, Inc.）、決済：Stripe, Inc. 等）に対し、利用目的の達成に必要な範囲で取り扱わせる場合。これらの委託先は日本国外に所在することがあります。

5. 安全管理措置

当社は、個人情報の漏えい・滅失・毀損の防止のため、合理的な安全管理措置を講じます。ただし、インターネットを通じた通信・保管には一定のリスクが伴い、当社はこれを完全に排除できるものではなく、合理的な範囲を超える保証は行いません。

6. データの書き出し・削除

利用者は、本サービスの画面から自社データの書き出し（JSON／CSV／Excel）および削除を行うことができます。解約後に当社側に残るデータは、合理的な期間（解約日から90日）の経過後に順次削除します。

7. 開示・訂正・利用停止等の請求

ご本人からの個人情報の開示・訂正・追加・削除・利用停止等のご請求については、下記のお問い合わせ窓口までご連絡ください。当社所定の手続により、法令に従って対応します。

本サービスは、その動作のためにブラウザのローカルストレージ（IndexedDB 等）を使用します。これらは本サービスの提供に必要な範囲で利用されます。
